## Sobre

Desenvolvedor full stack com foco em interfaces web e sistemas integrados a back-end. Trabalho principalmente com **JavaScript, PHP, HTML e CSS**, utilizando os frameworks **Angular, React, Next.js e Vue** conforme a necessidade do projeto.

- Desenvolvimento de interfaces (frontend) e integração com APIs e serviços de back-end
- Experiência em sistemas SaaS, dashboards e aplicações web completas
- Ambiente de desenvolvimento em Ubuntu
